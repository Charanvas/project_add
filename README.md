# 🚀 Project Add

An AI-powered project management and collaboration platform designed to streamline idea organization, task tracking, team coordination, and intelligent project execution workflows.

---

# 🌟 Overview

Project Add is a modern productivity and project orchestration system that helps individuals, startups, and teams efficiently manage projects from ideation to deployment.

The platform integrates:
- Task management
- Collaboration tools
- AI-assisted planning
- Workflow automation
- Progress tracking
- Intelligent prioritization

The goal is to transform fragmented project execution into a centralized intelligent workflow system.

# 🚀 Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Charanvas/project_add.git
cd project_add
```

---

## 2️⃣ Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Linux / Mac

```bash
source venv/bin/activate
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Configure Environment Variables

Create a `.env` file:

```env
SECRET_KEY=your_secret_key
DATABASE_URL=your_database_url
AI_MODEL=qwen
```

---

## 5️⃣ Run Application

```bash
python app.py
```
